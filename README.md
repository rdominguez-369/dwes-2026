# DWES 2026

## Descripción

Repositorio destinado a las prácticas y actividades del módulo de Desarrollo Web en Entorno Servidor (DWES).

El objetivo de este proyecto es aplicar de forma práctica los contenidos aprendidos durante el curso, incluyendo el uso de Git y GitHub para el control de versiones y la gestión del proyecto.

## Tecnologías utilizadas

Actualmente, el proyecto utiliza las siguientes herramientas y tecnologías:

- Git
- GitHub
- Visual Studio Code
- Markdown

Esta sección se actualizará a medida que se incorporen nuevas tecnologías durante el desarrollo del proyecto.

## Estructura del proyecto

El proyecto está organizado de la siguiente manera:

dwes-2026/
├── docs/
├── public/
├── src/
├── .gitignore
└── README.md

- `docs/`: documentación relacionada con el proyecto.
- `public/`: archivos públicos del proyecto.
- `src/`: código fuente del proyecto.
- `.gitignore`: especifica los archivos y carpetas que Git debe ignorar.
- `README.md`: contiene la información y documentación principal del proyecto.

## Cómo ejecutar el proyecto

Actualmente, el proyecto se encuentra en una fase inicial y todavía no dispone de una aplicación ejecutable.

Las instrucciones de ejecución se añadirán cuando se incorpore el código necesario para ejecutar el proyecto.
